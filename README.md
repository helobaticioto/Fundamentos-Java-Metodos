# Fundamentos Java - Método
Uma série de exercícios simples de treinamento fundamental em Java para aperfeiçoamento de práticas de método.

### `Divisores de um número (DivisoresDeUmNumero)`

- O programa JAVA lê um valor inteiro e positivo (possui validação de entrada). Imprime todos os seus divisores
inteiros, positivos e negativos. A leitura fica no main(); a impressão dos
divisores, em um método.

### `Classificação de triângulos (ClassificacaoDeTriangulos)`

- O programa JAVA lê três valores. Se formarem um triângulo, imprime a classificação quanto
aos lados: equilátero, isósceles ou escaleno. Um triângulo existe quando cada
lado é menor que a soma dos outros dois. A leitura fica no main(); a
classificação, em outro método.

### `O maior de três valores (Maior3Valores)`

- O Programa Java lê 3 valores inteiros. Este contém um método que determina e
RETORNA o maior valor digitado. A impressão do maior valor foi feita no
main().
